# Fonts

The fonts aren't in the repo, but they're all free and open-licensed. Download them and put the files here, in
`assets/fonts/`, with exactly these names (rename where needed, e.g. `JetBrainsMono-Regular.ttf` → `JBMono-400.ttf`).
Google Fonts serves some families as one variable font; for those, use the static file for the weight listed.

The fonts marked **the engine** are needed for everything; the rest only for the songs listed next to them.

The two Three.js films are browser films: they load their fonts from their own `web/fonts/` folder (`songs/i-have-a-blocker/web/fonts/`, `songs/ragnarok-or-reach-for-mars/web/fonts/`), so put copies of the fonts they use there too.
